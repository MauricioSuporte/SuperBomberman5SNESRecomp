# Application icon

`app.ico` was converted from `5Icon.png`, supplied by MauricioSuporte and
explicitly requested for the application and release. It was not extracted
from the ROM by this project. The source image is a transparent 98 × 106 PNG;
its visible bounds were cropped and scaled proportionally onto square canvases
without clipping. The ICO includes 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256
pixel variants. `app.rc` embeds it in Windows setup and playable executables.

The supplied game-themed artwork is not covered by the project's software
license; rights to Bomberman branding and game artwork remain with their
respective holders. The supplied image's original author/license was not
provided. No broader permission to reuse game artwork is claimed.
