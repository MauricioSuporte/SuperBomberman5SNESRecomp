# README images / Imagens do README

`five-player-showcase.png` (1028 × 900) combines four frames captured on
2026-10-14 from this project's own Linux LLE build (v0.6.0 sources), at the
maintainer's explicit request, to show optional features on the repository page:

| Position | Scene | Mods |
|---|---|---|
| Top left | Title, five-player Normal Game menu (English, no translation) | Normal co-op |
| Top right | Battle character selection: Subordinate Bomber in the former X cell, five characters in different colors | Subordinate Bomber, colors |
| Bottom left | Zone 1-1 with five players, including Subordinate Bomber, each with its own character and color | Co-op, character selection, colors, Subordinate Bomber |
| Bottom right | Battle Mode stage 1 with five players, including a yellow Subordinate Bomber | Colors, Subordinate Bomber |

Each frame is a 256 × 224 rendering scaled 2× with nearest-neighbour sampling.

displayed as a screenshot of the running software and is not a source asset,

release downloads. No other screenshots or extracted graphics are tracked.
