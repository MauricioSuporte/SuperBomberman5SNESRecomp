`five-player-showcase.png` (1028 × 900) combines four frames captured from
this project's own Linux LLE builds on 2026-10-16 (v0.12.0 sources), at the
maintainer's explicit request, to show the optional features on the
repository page:

| Position | Scene | Mods |
|---|---|---|
| Top left | Title, five-player Normal Game menu | Normal co-op |
| Top right | Normal Game character selection with three rows: Jet, Lady, Honey, Kotetsu and Great Bomber chosen, Super Bomberman 4 portraits, colors changed with L/R, Subordinate Bomber in the X cell | Co-op, character selection, colors, Subordinate Bomber, Bomber Kings |
| Bottom left | Zone 1-1 with those five players using their abilities: Jet's flight and fire trail, Lady's laser, Honey's shot, Kotetsu's thrust (Great blinks, invulnerable) | Same |
| Bottom right | Battle Mode stage 1: Super Bomberman 4's Bomberman, Bazooka's fire beam, Hammer, Honey's shot and a green Subordinate Bomber, in changed colors | Colors, Subordinate Bomber, Bomber Kings |

The Super Bomberman 4 characters are drawn at runtime from the maintainer's
own Super Bomberman 4 ROM; no data from it is stored in the repository. Each
frame is a 256 × 224 rendering scaled 2× with nearest-neighbour sampling.
Player positions in the two gameplay frames were set with scripted pokes so
the abilities have room. The pictured game artwork belongs to its respective
rights holders; it is displayed as a screenshot of the running software and is
not a source asset, is not covered by the project's software license and is
never packaged in release downloads. No extracted graphics are tracked.
