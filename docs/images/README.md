# README images / Imagens do README

`five-player-showcase.png` (1028 × 900) combines four frames captured from
this project's own Linux LLE builds, at the maintainer's explicit request, to
show optional features on the repository page. The top-left frame was
captured on 2026-10-14 (v0.6.0 sources); the other three were recaptured on
2026-10-15 from the v0.9.0 sources:

| Position | Scene | Mods |
|---|---|---|
| Top left | Title, five-player Normal Game menu (English, no translation) | Normal co-op |
| Top right | Battle character selection with six columns: Honey, Kotetsu, Subordinate Bomber and two stock characters in different colors | Honey and Kotetsu, Subordinate Bomber, colors |
| Bottom left | Zone 1-1 with five players, each with its own character and color: Honey, Kotetsu, Subordinate Bomber and two stock characters | Co-op, character selection, colors, Subordinate Bomber, Honey and Kotetsu |
| Bottom right | Battle Mode stage 1 with five players: Honey, Kotetsu, a green Subordinate Bomber and two stock characters in other palettes | Colors, Subordinate Bomber, Honey and Kotetsu |

Each frame is a 256 × 224 rendering scaled 2× with nearest-neighbour sampling.
The pictured game artwork belongs to its respective rights holders; it is
displayed as a screenshot of the running software and is not a source asset,
is not covered by the project's software license and is never packaged in
release downloads. No extracted graphics are tracked.
