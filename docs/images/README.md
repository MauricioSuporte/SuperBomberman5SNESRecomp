# README images / Imagens do README

`five-player-showcase.png` (1028 × 900) combines four frames captured on
2026-10-14 from this project's own Linux LLE build, at the maintainer's explicit
request, to show optional features on the repository page:

| Position | Scene | Mods |
|---|---|---|
| Top left | Title, five-player Normal Game menu (English) | Normal co-op |
| Top right | Zone 1-1 with five players, five characters and colors | Co-op, character selection, colors |
| Bottom left | Zone 1-A boss stage; four players fight beside the rival bomber | Co-op, character selection, colors |
| Bottom right | Battle Mode stage 1 with five human players, five characters and colors | Character selection colors |

Each frame is a 256 × 224 rendering scaled 2× with nearest-neighbour sampling.
The pictured game artwork belongs to its respective rights holders; it is
displayed as a screenshot of the running software and is not a source asset,
is not covered by the project's software license and is never packaged in
release downloads. No other screenshots or extracted graphics are tracked.
